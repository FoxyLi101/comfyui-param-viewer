    使用说明

    它读取什么

    ComfyUI 默认会把两份 JSON 写进输出文件：prompt（API 执行图，节点与真实输入值）和 workflow（前端画布，布局与节点标题）。本工具优先用 prompt 展示参数，并用 workflow 补全标题、分组与流程图。

    容器元数据位置
    PNG / APNGtEXt / zTXt / iTXt 文本块
    JPEGEXIF UserComment / ImageDescription，或 COM 注释
    WebPEXIF 标签，常见值为 prompt:{…} / workflow:{…}
    GIFComment 扩展块
    MP4 / MOV / AVIF容器元数据标签（©cmt、©des、freeform 等）
    WebM / MKVEBML Tags（TagName / TagString）
    JSON直接识别 API prompt 或 UI workflow

    为什么可能读不到

    • 启动 ComfyUI 时用了 --disable-metadata，或保存节点关闭了元数据。
    • 文件被微信、截图工具、转码器、图床等重新编码，元数据被剥离。
    • 视频保存节点没有把 prompt / workflow 写进容器标签。
    • 文件只有 workflow 没有 prompt，节点值只能按 widgets_values 顺序展示。

    隐私

    所有解析都在本地浏览器完成，文件不会上传到任何服务器；页面不发起网络请求。
